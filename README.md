
## Referans Depo Analizi (Güncelleme)
Belirtilen `AMN-4W` ve `AMN-4W-jules` depoları GitHub üzerinde kontrol edilmiş ancak `HTTP 404` hatası alınmıştır. Depolar "Private" olduğu için erişim sağlanamamaktadır. Bu doğrultuda, daha önce kurulmuş olan mimari ve kod tabanı üzerinde iyileştirmeler yapılarak ilerlenmiştir.
